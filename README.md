# DEVTOOLIO

Developer tools without the friction. Calculators, converters, image and file helpers, writing editors, and developer utilities — most of them run in the browser.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production URL

Canonical links use `https://www.devtoolio.tech`. `https://devtoolio.tech` redirects to the same path on www. If `NEXT_PUBLIC_SITE_URL` is set to either of those hosts, it still resolves to www.

Optional env vars:

- `NEXT_PUBLIC_SITE_URL`
- `NEXT_PUBLIC_CONTACT_EMAIL`
- `NEXT_PUBLIC_ADSENSE_CLIENT`
- `NEXT_PUBLIC_ADSENSE_SLOT`
- `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`
